# Archived Dashboard Planning Records

These files document the retired FHSS-first dashboard planning and execution
history through Phase 2B. They are preserved for traceability and are not
current implementation authority.

Current dashboard authority is:

- `plan/Phase2B_Generic_Graph_Management.md`
- `plan/Phase2B_Corrected_Implementation_Specification.md`
- `plan/GRAPHX_GENERIC_GRAPHICAL_DASHBOARD_PLAN.md`
- `docs/graphx_dashboard.md`

The current architecture has one generic Graph Management implementation.
FHSS is a graph/data specialization displayed through that implementation; it
does not own a parallel dashboard management stack.

Links inside archived records may retain their original repository-relative
paths and should be interpreted as historical references.
