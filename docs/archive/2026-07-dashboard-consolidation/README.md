implementation planning, and conformance analysis. These records are retained
for historical traceability only.

Use the following current documents instead:

- `docs/graphx_dashboard.md` for architecture and implementation status
- `plan/GRAPHX_GENERIC_GRAPHICAL_DASHBOARD_PLAN.md` for graphical-display work
- `plan/Phase2B_Generic_Graph_Management.md` and
  `plan/Phase2B_Corrected_Implementation_Specification.md` for the existing
  generic Graph Management contract

Operator manuals and implementation-facing compatibility material that remain
under `docs/` are not made authoritative by this archive.
